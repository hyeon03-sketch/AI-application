# L10 · 주석자 A·B 일치도를 모델 성능 상한으로 (탐색) / annotator agreement as a ceiling (exploratory)

주석자 B를 A의 "예측"으로 보고(반대도) 모델과 같은 녹화·같은 지표로 채점했다. 모델 점수가 이 값에 가까우면 더 올릴 여지가 작다. κ 95% CI = 참가자 bootstrap, null p95 = 참가자 안에서 B 라벨 섞기 2000회.
Annotator B is scored as a "prediction" of A (and vice versa) on the same recordings and metric as the models.
