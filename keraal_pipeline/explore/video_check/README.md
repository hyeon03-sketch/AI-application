## 1. fps (`fps_check.py`)
- 영상은 전 그룹 **10 fps**, 프레임 수가 Kinect와 같다(1A 250/250, 2A 49/51, G3는 대부분 ±2 이내).
- 주석자 B의 Global evaluation 종료 = 모든 녹화에서 영상 길이 × 2/3 → 주석 도구가 15 fps로 재생했다.
- 결론: **프레임 = 주석 시간 × 15** (기존 처리 맞음). 실제 촬영 속도는 미확정이다. 영상 파일 헤더는 10 fps, 주석 도구는 15 fps이고 어느 쪽이 실제 시간인지 근거가 없다. 초 단위 수치를 보고할 때는 "주석 시간 기준"이라고 적는다.

## 2. 2A S1 동일인 여부 (`bones.py`, `2A_S1_brest_vs_roscoff.png`)
- 상체 뼈 길이로는 구분 불가: 사람 간 거리(약 1 cm)가 같은 사람의 녹화 간 편차(1.1 cm)와 비슷하다.
- 영상: 얼굴 블러, 방이 다르고(Brest 흰 방 / Roscoff 주황 벽 방) 옷도 다르다. 체격은 비슷하다.
- 결론: **판정 불가 → 지금처럼 분리 유지**(보수적). 확정하려면 저자 확인이 필요하다.
